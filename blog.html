1. HTML — a estrutura das páginas

HTML (HyperText Markup Language) não é uma linguagem de programação — é uma linguagem de marcação. Escreves etiquetas (tags) à volta do conteúdo para dizer ao navegador o que cada coisa é.

Cada tag abre e fecha: <p>texto</p>. Algumas não fecham: <br> e <img>.

Comandos principais

ComandoPara que serve
<!DOCTYPE html>Diz ao navegador que o documento usa HTML5. Sempre na primeira linha.
<html>Envolve toda a página.
<head>Zona de informação: título da aba, codificação, CSS.
<title>Texto que aparece no separador do navegador.
<body>Tudo o que aparece visível na página.
<h1>…<h6>Títulos. <h1> é o maior, <h6> o menor.
<p>Parágrafo de texto.
<b> / <i> / <u>Negrito / itálico / sublinhado.
<br>Quebra de linha.
<hr>Linha horizontal a separar conteúdo.
<a href="...">Cria um link.
<img src="...">Insere uma imagem.
<ul> / <ol> / <li>Lista com pontos / numerada / item da lista.
<div> / <span>Caixa de bloco / pedaço pequeno em linha.
<table> <tr> <td>Tabela, linha e célula.
<form> <input> <button>Formulário, caixa de texto, botão.
<style>Escreve CSS dentro da página.
<!-- … -->Comentário (não aparece).

Exemplo completo — site com estilo

<!-- guarda como index.html e abre no navegador --> <!DOCTYPE html> <html> <head> <title>Loja do João</title> <meta charset="UTF-8"> <style> body { font-family: Arial; background: #f4f4f4; margin: 0; } .topo { background: #1E2761; color: white; padding: 20px; } .caixa { background: white; padding: 15px; margin: 15px; border-radius: 8px; } table { border-collapse: collapse; } td, th { border: 1px solid #ccc; padding: 6px 12px; } </style> </head> <body> <div class="topo"> <h1>Loja do João</h1> <p>Produtos frescos todos os dias</p> </div> <div class="caixa"> <h2>Preços</h2> <table> <tr><th>Produto</th><th>Preço</th></tr> <tr><td>Arroz 1kg</td><td>120 MT</td></tr> <tr><td>Óleo 1L</td><td>180 MT</td></tr> </table> </div> </body> </html>
Dica: guarda o ficheiro como index.html e abre com duplo clique — abre logo no navegador. Não precisas de instalar nada.

2. Python — ordens ao computador

Python é uma linguagem de programação a sério: calcula, decide, repete e guarda informação. Não usa chavetas — a organização é feita por indentação (os espaços no início da linha).

Comandos principais

ComandoPara que serve
print("olá")Escreve texto ou valores no ecrã.
nome = "João"Cria uma variável.
input("Nome: ")Pergunta algo ao utilizador.
int() / float() / str()Converte para inteiro, decimal ou texto.
if / elif / elseToma decisões.
for x in range(5):Repete N vezes.
while cond:Repete enquanto a condição for verdadeira.
break / continueSai do ciclo / salta para a próxima.
def funcao():Cria uma função.
return valorDevolve um resultado da função.
lista = [1, 2, 3]Lista de valores.
lista.append(4)Acrescenta ao fim.
len(lista)Quantos elementos tem.
dic = {"a": 1}Dicionário chave/valor.
import mathTraz bibliotecas extra.
open("f.txt", "w")Abre ficheiro para ler (r) ou escrever (w).
try / exceptTenta executar e apanha o erro.

Exemplo — programa da mercearia

# --- Programa da mercearia --- print("== MERCEARIA DO JOÃO ==") precos = {"arroz": 120, "oleo": 180, "acucar": 95} carrinho = [] nome = input("Qual é o seu nome? ") print("Bem-vindo,", nome) while True: print("\nProdutos disponíveis:") for produto, preco in precos.items(): print("- ", produto, "=", preco, "MT") escolha = input("Escreva o produto (ou 'fim'): ") if escolha == "fim": break elif escolha in precos: quantidade = int(input("Quantas unidades? ")) carrinho.append((escolha, quantidade, precos[escolha] * quantidade)) print("Adicionado!") else: print("Esse produto não existe.") total = 0 print("\n===== FACTURA =====") for item, qtd, subtotal in carrinho: print(item, "x", qtd, "=", subtotal, "MT") total = total + subtotal print("TOTAL: ", total, "MT")
Dica: a indentação (4 espaços) não é decoração — define o que está dentro do if, for ou função.

3. Lua — leve, rápida, usada em jogos

Lua é pequena e muito rápida. Usada em Roblox, World of Warcraft, sistemas embebidos. Os blocos abrem com uma palavra e fecham sempre com end.

Comandos principais

ComandoPara que serve
print("olá")Mostra texto no ecrã.
local nome = "João"Cria uma variável local (recomendado).
io.read()Lê o que o utilizador escreve.
tonumber() / tostring()Converte texto ↔ número.
..Junta (concatena) dois textos.
if … then … endDecisão (usa elseif / else).
for i = 1, 10 do … endRepete de 1 até 10.
while cond do … endRepete enquanto verdadeiro.
repeat … until condRepete até a condição ser verdadeira.
function nome() … endCria uma função.
tabela = {1, 2, 3}Tabela (lista) — começa no índice 1.
ipairs(tabela)Percorre índices e valores.

Exemplo — jogo de adivinhar o número

-- Jogo: adivinha o número secreto math.randomseed(os.time()) local secreto = math.random(1, 100) local tentativas = 0 print("=== JOGO DA ADIVINHA ===") io.write("Como te chamas? ") local nome = io.read() print("Boa sorte, " .. nome .. "! Pensei num número de 1 a 100.") local palpite repeat io.write("O teu palpite: ") palpite = tonumber(io.read()) tentativas = tentativas + 1 if palpite == nil then print("Isso não é um número!") elseif palpite < secreto then print("Muito baixo!") elseif palpite > secreto then print("Muito alto!") else print("Acertaste em " .. tentativas .. " tentativas!") end until palpite == secreto
Dica: esquecer o end é o erro mais comum em Lua. Conta sempre quantos blocos abriste.

4. JavaScript — dar vida às páginas

Se o HTML é o esqueleto, o JavaScript é o músculo: faz o botão funcionar, valida formulários, muda textos sem recarregar a página e cria animações.

Comandos principais

el.innerHTML = "..."Muda o conteúdo.
el.style.colorAltera estilo pelo código.
el.addEventListener("click", f)Executa f no clique.

Exemplo — calculadora de gorjeta

<!DOCTYPE html> <html><head> <title>Calculadora de Gorjeta</title> <style> body { font-family: Arial; background:#eef2f7; padding:30px; } .cartao { background:#fff; max-width:340px; padding:20px; border-radius:10px; } input, button { padding:8px; width:100%; margin-top:8px; } button { background:#1E2761; color:#fff; border:none; cursor:pointer; } </style></head><body> <div class="cartao"> <h1>Calculadora de Gorjeta</h1> <input type="number" id="conta" placeholder="Ex: 500"> <button id="botao">Calcular</button> <h2 id="resultado"></h2> </div> <script> const botao = document.getElementById("botao"); function calcular() { let valor = Number(document.getElementById("conta").value); if (valor <= 0 || isNaN(valor)) { document.getElementById("resultado").innerHTML = "Valor inválido!"; return; } const gorjeta = valor * 0.10; const total = valor + gorjeta; document.getElementById("resultado").innerHTML = "Gorjeta: " + gorjeta.toFixed(2) + "MT<br>Total: " + total.toFixed(2) + "MT"; document.getElementById("resultado").style.color = "green"; } botao.addEventListener("click", calcular); </script> </body></html>
Dica: abre a consola do navegador com F12 para ver os console.log() e erros.

5. Resumo comparativo

Mostrar uma mensagem

LinguagemCódigo
HTML<p>Olá mundo</p>
Pythonprint("Olá mundo")
Luaprint("Olá mundo")
JavaScriptconsole.log("Olá mundo");

Repetir 3 vezes

# Python for i in range(3): print(i) -- Lua for i = 1, 3 do print(i) end // JavaScript for (let i = 0; i < 3; i++) { console.log(i); }

Tomar uma decisão

# Python if idade >= 18: print("Adulto") else: print("Menor") -- Lua if idade >= 18 then print("Adulto") else print("Menor") end // JavaScript if (idade >= 18) { console.log("Adulto"); } else { console.log("Menor"); }

Diferenças que deves memorizar

  • HTML não tem lógica — só estrutura o conteúdo.
  • Python organiza blocos por indentação, sem ponto e vírgula.
  • Lua fecha todos os blocos com end e junta textos com ..
  • JavaScript usa chavetas { } e ponto e vírgula ;
  • Em Lua as tabelas começam no índice 1; em Python e JS no 0.

Como praticar

  • HTML e JS: cria um ficheiro .html no bloco de notas e abre no navegador.
  • Python: instala o Python e escreve ficheiros .py, ou usa um editor online.
  • Lua: usa um interpretador Lua ou o editor do Roblox Studio.
  • Regra de ouro: escreve o código à mão em vez de copiar. Erra, lê o erro e corrige — é assim que se aprende.
